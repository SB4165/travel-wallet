# 여행지갑 (Travel Wallet · VND)

개인용 베트남(푸꾸옥) 여행 웹앱. GitHub Pages로 배포되며, 휴대폰 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 기능
| 탭 | 내용 |
|---|---|
| 지갑 | 1,000~500,000동 지폐별 장수 입력 → 상단/하단 총액(동·원화). 기기에 자동 저장 |
| 계산 | `+` `−` `할인%` `=` 계산기, 총액 동/원화 표시. 할인은 그 시점까지의 합계에 적용 |
| 일정 | 구글 시트(푸꾸옥 탭) 실시간 연동 — 전체 일정 / 일별 타임라인, PNG 이미지 저장 |

- 환율: [ExchangeRate-API](https://open.er-api.com) 실시간(3시간 캐시), 실패 시 대체 API → 상단 환율 배지를 눌러 수동 입력 가능
- 일정: 앱 열 때, 탭 전환 시, 1분마다 자동으로 시트를 다시 읽음 (⟳ 버튼으로 즉시 갱신)

## 설정
- 시트 변경: `app.js` 상단 `SHEET_ID`, `SHEET_GID` 수정
- 시트는 **링크가 있는 모든 사용자 → 뷰어** 공유 필요
- 시트 형식: 날짜 행(`11/5` 등)을 자동 인식 → 바로 윗행=요일, 아래행=테마, 가장 긴 행=상세 일정(`HH:MM 제목 / 그랩 10분`, 하위 `- 내용`, `* 참고`), `일출/일몰` 행, 요약 행, 기타 셀은 메모로 표시

## 홈 화면에 추가
- iPhone(Safari): 공유 → 홈 화면에 추가
- Android(Chrome): ⋮ → 앱 설치 / 홈 화면에 추가
