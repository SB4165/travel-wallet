# 여행지갑 (Travel Wallet · VND)

개인용 베트남(푸꾸옥) 여행 웹앱. GitHub Pages로 배포되며, 휴대폰 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 기능
| 탭 | 내용 |
|---|---|
| 지갑 | 1,000~500,000동 지폐별 장수 입력(지폐마다 원화 환산 표시) → 상단/하단 총액(동·원화). 자동 저장 + 저장 버튼/시각 표시 |
| 결제 | 금액(동 또는 원화)·내용·분류·현금/카드 기록, 날짜별 합계. 현금은 낼 지폐·거스름돈 자동 추천(수정 가능) 후 지갑에서 자동 차감, 삭제 시 원복 |
| 충전 | ATM 출금 / 환전(5만원권·1만원권 장수) 기록 → 받은 지폐가 지갑에 자동 추가, 실제 적용 환율 계산, 삭제 시 원복 |
| 계산 | `+` `−` `할인%` `=` 계산기, 총액 동/원화 표시. 할인은 그 시점까지의 합계에 적용 |
| 일정 | 구글 시트(푸꾸옥 탭) 실시간 연동 — 전체 일정 / 일별 타임라인, PNG 이미지 저장, 날짜별 요약 자동 생성, 앱에서 바로 편집(✎) |
| 회화 | 베트남어 회화 45개(기본·식당·카페·계산·결제·쇼핑·흥정·마사지), 검색, 누르면 크게 보여주기, 베트남어 음성 듣기(지원 기기) |

- 환율: [ExchangeRate-API](https://open.er-api.com) 실시간(3시간 캐시, 100동 기준 표시), 실패 시 대체 API → 상단 환율 배지를 눌러 수동 입력 가능
- 일정: 앱 열 때, 탭 전환 시, 1분마다 자동으로 시트를 다시 읽음 (⟳ 버튼으로 즉시 갱신)

## 설정
- 시트 변경: `app.js` 상단 `SHEET_ID`, `SHEET_GID` 수정
- 시트는 **링크가 있는 모든 사용자 → 뷰어** 공유 필요
- 시트 형식: 날짜 행(`11/5` 등)을 자동 인식 → 바로 윗행=요일, 아래행=테마, 가장 긴 행=상세 일정(`HH:MM 제목 / 그랩 10분`, 하위 `- 내용`, `* 참고`), `일출/일몰` 행, 요약 행, 기타 셀은 메모로 표시

## 앱에서 일정 편집 (최초 1회 설정)
1. 구글 시트 → 확장 프로그램 → Apps Script → `gas/Code.gs` 내용 붙여넣기 (앱의 ⚙ 설정에서 `코드 복사` 가능)
2. 첫 줄 `TOKEN`을 나만 아는 비밀번호로 변경 후 저장
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → 권한 승인
4. 앱 일정 탭 ⚙ → 웹 앱 URL·비밀번호 입력 → 연결 테스트
- 저장 시 시트 내용이 그 사이 바뀌었으면 덮어쓰지 않고 경고합니다.
